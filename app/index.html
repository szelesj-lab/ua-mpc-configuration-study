UA-MPC battery simulation

Runs deterministic and uncertainty-aware MPC of a behind-the-meter battery on any load profile. Runs wait in a queue and run one after another.
User guide
SimulationPaper check

Upload a CSV with a timestamp and a load column (15, 30 or 60 min; kW, W or kWh per interval). Weather, prices and renewable forecasts come from the reference site; the forecast models are retrained before every simulated month (walk-forward). Add as many runs as you like: they are queued and run one after another. With the reference data set and the reference settings the results are also compared with the stored results of the same set-up.
