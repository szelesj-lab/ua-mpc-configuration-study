          Connecting the real system (live measurements)
          
The system sends measurements as JSON to POST /api/live. Every field except the time is optional. Times without a UTC offset are read as site local time.

          

          
Enable live data under Configuration → Live measurements. To test without the real system, run python src/live_simulator.py --backfill 6. To accept data from other computers, start the dashboard with --host 0.0.0.0 and set an API token.
